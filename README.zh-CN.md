## 🧰 作品

按用途分四组，和网站上的 [WORKS](https://www.longarcsociety.com/works) 一样。Skill 都收在 [jianing-skills](https://github.com/Jianing1117/jianing-skills) 合集里 ![stars](https://img.shields.io/github/stars/Jianing1117/jianing-skills?style=flat&label=stars&color=B8D9EA)，Claude Code、Codex 和其他能读 `SKILL.md` 的 Agent 都能装。

**📈 资产配置**

- **[家庭财务体检](https://github.com/Jianing1117/household-financial-checkup)** · [在线使用](https://www.longarcsociety.com/tools/checkup)<br>在误以为炒股和vc是“投资”很久以后，我才意识到资产配置是个人投资最重要的概念之一。这个工具可以帮助你彻底看清自己家的财务健康状况并拿到一页家庭投资政策书。不用注册，数据只存在你自己的浏览器里。

**💻 效率提升**

- **[AI 电脑体检](https://github.com/Jianing1117/mac-ai-checkup)**<br>AI 时代，电脑里 AI 留下的垃圾和装的工具越来越多。给你自己的 AI 装一份清理 Mac / 优化使用 的经验：别漏掉最占地方的那几块，也别删错东西。
- **[刘海记 NotchPad](https://github.com/Jianing1117/notchpad)** · [下载](https://github.com/Jianing1117/notchpad/releases/latest)<br>MacBook 刘海里的轻量便签，可以定制你的待办todo、日常灵感、工作流程进度。鼠标碰到刘海就展开，移开就收起。数据联动苹果自带的「提醒事项」和「备忘录」。

**🪞 自我觉察**

- **[观自在 · MindMirror](https://github.com/Jianing1117/jianing-skills/tree/main/mindmirror)**<br>帮助你在AI时代进行全面的自我觉察：“照见”看当下，读你自己的全部语料，回答 22 个犀利的自我认知问题；“数字分身”看过去，通过深度访谈和结构提炼，打造你的核心上下文；“人生规划”看未来，5个维度推演未来五年的路，帮你走出奥德赛时期。

**✍️ 内容创作**

- **[内容引擎](https://github.com/Jianing1117/jianing-skills/tree/main/content-engine)**<br>拆你认可的爆款帖子并总结提炼规律，帮助诊断和修改自己的稿子，再用发布后的数据校准方法。
- **[内容定位](https://github.com/Jianing1117/jianing-skills/tree/main/awesome-creator-positioning)**<br>给刚起步的抖音、小红书创作者定方向，给出一句话定位、内容边界、初始主线和对标账号。起号前跑一次。
- **[白板封面](https://github.com/Jianing1117/jianing-skills/tree/main/awesome-creator-cover)**<br>把标题和要点做成白板风格的小红书、抖音封面，输出可以继续编辑的 Excalidraw 文件。
- **[IP 形象指南](https://github.com/Jianing1117/jianing-skills/tree/main/ip-cartoon-guide)**<br>从一张照片做出可以反复使用的个人 IP 卡通形象，再用同一个角色画文章和项目的配图。
- **[Super Slides 演示稿](https://github.com/Jianing1117/jianing-skills/tree/main/super-slides)**<br>先定大纲再做设计，生成一份打开就能放映的网页演示稿，需要时再导出 PDF 或 PPT。
- **[公众号排版](https://github.com/Jianing1117/jianing-skills/tree/main/wechat-formatter)**<br>把一篇 Markdown 文章按文章类型自动选版式，转成能直接粘贴进公众号后台的排版，同时生成封面图。
- **[Screen Studio 智能初剪](https://github.com/Jianing1117/screenstudio-edit)**<br>让 AI 给 Screen Studio 录屏做初剪：剪掉空白停顿、失败的重录和口误，另存一个还能继续精修的工程副本，原工程一个字节都不改。重活由本机脚本完成，AI 只读转写文字，token 用得很少。

## 🤝 几条约定

- 只放自己用过且觉得有价值的内容。
- 代码全部公开，不推荐任何产品。
- 数据留在你自己手里。财务体检只存在你的浏览器里，刘海记用的是苹果自带的提醒事项和备忘录。
- 动你的东西之前先问。电脑体检删除只进废纸篓，MindMirror 读你的材料之前先确认范围。
- 所有流程代码在不影响目的前提下，尽量简洁。
